# Midnight Velvet 21・午夜魅影情趣 21 點

專為情侶打造的線上遠距離情趣博弈遊戲。

## 🌟 遊戲特色
1. **極致微醺奢華視覺**：波爾多紅絲絨酒紅、黑曜石午夜紫、香檳金箔質感配色，搭配動態流光光暈。
2. **Web Audio 擬真音效合成**：發牌滑動、籌碼撞擊、心跳重音、開香檳獲勝音效（純 Web Audio API 合成，零外部音檔依賴）。
3. **WebRTC 零伺服器遠距離連線**：使用 PeerJS 雲端節點，只要房主產生 6 碼房號或專屬邀請連結，另一半點擊即可直連，超低延遲同步！
4. **褪裳與情趣懲罰機制**：
   - 4 層裝備追蹤（外套/飾品 -> 上著 -> 下著 -> 貼身私密）。
   - 落敗時可在「褪去一件裝備」與「抽取情趣火辣指令」中二選一。
   - **Blackjack 王牌爆擊**：拿到 21 點享有「絕對命令權」！
5. **遠距離心跳互動電波**：相隔兩地也能點擊「💓 傳送心跳」，對方手機/螢幕會產生劇烈震動與心跳重音。

## 🚀 10 秒免費發布成線上網頁（遠端雙人遊玩）

因為這是一個**完全獨立的單一 HTML 檔案**（所有樣式、音效、邏輯、連線皆已內建），你可以用以下任何一種最快速的方法獲得專屬線上網址：

### 方法 A：Netlify Drop（最快，免指令，10 秒拿到網址）
1. 開啟 [Netlify Drop](https://app.netlify.com/drop)。
2. 把包含 `index.html` 的資料夾直接拖曳丟進網頁中。
3. 5 秒內就會自動產生一個專屬公開 HTTPS 網址（例如：`https://midnight-21.netlify.app`）。
4. 打開網址，複製連結發給女友就能直接開始玩！

### 方法 B：Vercel
1. 登入 [Vercel](https://vercel.com)。
2. 匯入或拖曳此專案，即可獲得專屬網址。

### 方法 C：GitHub Pages
1. 上傳至 GitHub 倉庫。
2. 在 Settings -> Pages 中開啟 GitHub Pages，即可獲得 `https://<你的帳號>.github.io/<專案名>`。
